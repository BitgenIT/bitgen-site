# 🟢 BItGen — Educazione Digitale per Tutti

BItGen è un progetto di divulgazione informatica che spiega come funziona davvero la tecnologia che usiamo ogni giorno.

Niente trucchi decontestualizzati, niente linguaggio incomprensibile: solo spiegazioni chiare, pensate per chi vuole capire, non solo usare.

Il progetto nasce con l'idea che la comprensione reale della tecnologia sia accessibile a tutti, dai 14 ai 60 anni.
